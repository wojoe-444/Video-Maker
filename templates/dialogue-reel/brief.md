# Git in 60 seconds: brief

A dialogue reel (about 56 s, 9:16). Einstein explains commit, push, pull request and merge; Isaac Newton riffs.
Cast: `einstein`, `newton`. Background: `block-run`. Cards: title, commit, push, pr, merge, recap.

## Claims on screen or in the dialogue, with sources

| claim | source |
|---|---|
| A commit is a snapshot saved in your local repository | https://git-scm.com/book/en/v2/Getting-Started-What-is-Git%3F |
| Push uploads local commits to a remote (GitHub) | https://git-scm.com/docs/git-push |
| A pull request asks collaborators to review changes before they are merged | https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/proposing-changes-to-your-work-with-pull-requests/about-pull-requests |
| Merging joins a branch's history into another (main) | https://git-scm.com/docs/git-merge |
| Newton worked out calculus (fluxions) in 1665-66, while Cambridge was closed by the plague | https://en.wikipedia.org/wiki/Isaac_Newton (Early life; 1665-1667) |
| His calculus went unpublished for decades (Method of Fluxions, written 1671, published 1736) | https://en.wikipedia.org/wiki/Method_of_Fluxions |
| Newton and Leibniz fought a bitter priority dispute over calculus | https://en.wikipedia.org/wiki/Leibniz%E2%80%93Newton_calculus_controversy |
